# ATLAS — Materiais de validação (avaliador)

Este diretório contém materiais usados pelo responsável humano para planejar, executar e avaliar experimentos sobre a metodologia ATLAS.

## Conteúdo

- `VALIDATION_PROTOCOL.md`: procedimento, cenários, rubrica, falhas críticas e critérios de avaliação.
- `VALIDATION_REPORT.md`: modelo e registro das execuções, evidências, limitações e resultados.

## Regra de isolamento

**Não forneça estes documentos à IA que está sendo avaliada.** O protocolo inclui informações de referência específicas dos cenários e pode revelar respostas esperadas. A IA avaliada deve receber somente o ATLAS oficial e os materiais explicitamente definidos para a tarefa.

Este repositório é público. Portanto, ele não oferece confidencialidade contra descoberta por terceiros. Não inclua credenciais, dados pessoais ou conteúdo sigiloso. Para sigilo real do gabarito, use um repositório privado.

## Relação com o ATLAS

Estes arquivos são instrumentos externos de avaliação. Não fazem parte da metodologia operacional que uma IA precisa consultar para criar, organizar ou recuperar projetos. O ATLAS oficial permanece independente dos resultados e critérios específicos dos experimentos.
